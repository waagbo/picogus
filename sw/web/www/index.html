Volume

Changes are heard immediately. Use Save settings to keep them after a reboot.

Card mode

Switching mode restarts the card (like pgusinit /mode). Sound stops for a few seconds.

Settings

Settings apply immediately, like setting them with pgusinit. Ports, IRQ and DMA must match what DOS programs expect.

CD-ROM image

Images are read from the USB drive attached to the card.

mt32-pi

Standard MIDI

SysEx file

Messages go out between the messages of the running DOS program, at MIDI speed.

Firmware update

Use picogus.uf2 built for Pico W boards to keep this web page. Sound stutters while flashing and the card restarts when done.

Do not power off during the update. If it fails, upload again before restarting; as a last resort the Pico W can be flashed over USB with BOOTSEL.

WiFi network

The card reconnects right away; if the new network does not work, fix it with pgusinit /wifissid. Use Save settings to keep the new network.
